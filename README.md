# AURELIUS — закрытый торговый клуб

Одностраничный презентационный сайт закрытого торгового клуба.

## Локальный просмотр

Откройте файл `index.html` двойным щелчком. Сайт работает без сервера и без установки программ.

## Публикация

Сайт размещён на GitHub Pages:

`https://fatkullinar-eng.github.io/aurelius/`

## Структура

- `index.html` — страница сайта;
- `css/styles.css` — оформление;
- `js/script.js` — контакты и поведение страницы;
- `legal.html` — правовая информация;
- `assets/` — картинки и превью ссылки;
- `docs`-инструкция лежит вне репозитория, в рабочей папке проекта.

## Форма заявки

Кнопки «Запросить доступ» открывают форму. Отправка идёт через сервис Web3Forms.

Чтобы форма заработала:

1. Получите ключ доступа на `web3forms.com`, указав Яндекс.Почту, на которую должны приходить заявки.
2. В `index.html` найдите поле `name="access_key"` и замените `ВАШ_КЛЮЧ_WEB3FORMS` на полученный ключ.
3. Проверьте отправку тестовой заявки.

Ключ Web3Forms — публичный идентификатор, а не пароль от почты. Он привязан к адресу, указанному при получении ключа.

## Важно

Это черновая версия. Перед публикацией для клиентов нужно заменить:

- ссылку Telegram и почту в `js/script.js`;
- демонстрационные отзывы на реальные;
- реквизиты и условия в `legal.html`;
- декоративный график на реальные материалы, если они есть;
- проверить все обещания в текстах.

Пока в `index.html` стоит запрет индексации (`noindex`), чтобы черновик не попадал в поисковики. После замены данных запрет нужно снять.
